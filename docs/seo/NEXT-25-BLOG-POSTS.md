## Publishing guardrails

- Add a genuine author and reviewer, with a real publication and review date.
- Make the opening answer a visible “short answer” block, then add a table, diagrams, and FAQs.
- Use original photos, drawings, checklists, or measurement examples. Never invent client outcomes, decibel figures, RT60 changes, fire classifications, certifications, or performance data.
- Cite primary manufacturer, laboratory, and authority sources for technical claims.
- Before adding any topic, check Search Console and the existing Resource Center for overlap. Update the stronger existing page rather than splitting the same intent across multiple URLs.
